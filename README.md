# Manner Studio — Portfolio Website

A simple, responsive one-page portfolio starter for GitHub Pages.

## Files
- `index.html` — the complete website (HTML + CSS + a tiny JavaScript snippet).

## Publish with GitHub Pages
1. Create a new **public** GitHub repository named `manner-studio-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings.

## Before launch
Replace the sample project cards, descriptions, email address, and social links with approved Manner Studio content. The current project visuals are CSS placeholders, not final portfolio mockups.
